# Java-mini-test
**Request:** To create a mini-test system that combines methods for presenting and grading 4-choice quizzes.

**Specifications:**

**1:** * Hold question statements, choices, and correct answers as data.

**2:** * A method to display each question.

**3:** * A method to check the answers (tested using automated answers for this run).

**4:** * A method to tally and display the results.

# Overview
A console-based Java mini-test system that presents 4-choice multiple-choice questions, grades the user's answers in real time, and calculates the final score and evaluation.

# Objective
To practice and demonstrate core Java programming fundamentals, including:
* Managing data using arrays and multi-dimensional arrays (`String[]`, `String[][]`).
* Using loops (`for` loops) to dynamically handle questions and choices.
* Implementing modular code through separated methods (`runQuiz`, `checkResult`).
* Handling user input via the `Scanner` class and string comparison (`equalsIgnoreCase`).

# Key Concepts
* **Data Structures:** Storing questions, choices, and answers separately and mapping them using array indices.
* **Control Flow:** Using `for` loops to iterate through questions and print out choices systematically.
* **Method Modularization:** Breaking down complex tasks into smaller, reusable, and single-responsibility methods.
* **Input Validation & Grading:** Accepting user choices regardless of casing and tracking correct answers to calculate final percentages.

## Version History
* **Version 1 (Initial Approach):** Uses individual methods for each question and explicit checks for understanding basic control flow.
* **Version 2 (Refactored):** Uses arrays (`String[]`, `String[][]`) and loops (`for`) to make the code cleaner, shorter, and easier to scale with more questions.
